AI 시스템으로 문제 해결

이미지·소리·텍스트 데이터로 문제를 해결하는 방법을 연습해요.

학습 목표
  • 다양한 데이터를 활용하여 인공지능 시스템을 구성할 수 있다.
  • 문제 해결에 적합한 인공지능 시스템을 적용할 수 있다.

핵심 개념

🖼️ 이미지 분류

입력된 이미지를 분류 모델에 적용해 어떤 물체가 포함되었는지 자동으로 식별해요. (예: CCTV 위험 감지, 자동차 번호판 인식, 꽃 이름 찾기)

🔊 소리 분류

입력된 소리의 특징을 추출한 후 저장된 데이터와 비교해 분류해요. (예: 새소리로 종 구별, 보이스 피싱 음성 탐지, 숨소리로 호흡기 질환 탐지)

📝 텍스트 분류

텍스트의 의미와 의도를 이해해서 분류해요. (예: 가짜 뉴스 판별, 고객 리뷰 분석, 챗봇 답변, 스팸 메일 분류)

🛠️ 인공지능 모델 만들기

엔트리의 '인공지능 모델 학습하기'에서 분류 종류(이미지/소리/텍스트)를 고르고, 클래스별 데이터를 5개 이상 입력해 학습시켜요.

실습 — 어떤 데이터 유형이 필요할까?

문제를 해결하려면 이미지·소리·텍스트 중 어떤 데이터가 필요할지 골라보세요

실습 — 나만의 인공지능 모델 만들기

엔트리의 '인공지능 모델 학습하기'로 얼굴을 인식하는 로봇 강아지를 만드는 순서예요. 아래 순서를 따라 직접 만들어보세요.

  1. '인공지능' 블록 카테고리에서 '인공지능 모델 학습하기'를 선택한다.
  2. '학습할 모델 선택하기'에서 '새로 만들기'의 '분류: 이미지'를 선택하고 '학습하기'를 클릭한다.
  3. 모델 이름을 정하고, 클래스 이름을 각각 입력한다. (예: '주인', '다른 사람')
  4. 각 클래스에 해당하는 이미지를 5개 이상 업로드하거나 카메라로 촬영해 입력한다.
  5. '모델 학습하기'를 클릭해 학습을 진행하고, 새로운 데이터로 결과를 확인한다.
  6. 결과가 정확하면 '적용하기'를 클릭하고, 오브젝트를 추가해 프로그램을 완성한다.
